## 为什么国内访客场景总绕不开 CN2 GIA

线路决定了晚高峰你的网站还能不能打开。搬瓦工的线路分三层：普通 KVM 走常规国际线路，三网参考延迟 180ms 以上；CN2（GT）便宜但 2019 年后高峰期拥堵严重，官方自己都承认“基本和 AS4134 一样堵”；CN2 GIA 走 AS4809 的 GIA 网络，官方的描述是“传输中国方向数据最贵的方式”——IP transit 成本可达 $120/Mbps，换来的是“问题最少、非常稳定”的传输质量。

CN2 GIA-E（E-Commerce 版）是个折中产物：把洛杉矶 DC6/DC9 的 GIA 线路打包进可迁移的套餐，2.5Gbps 带宽起步，DC6 机房同时接电信 CN2 GIA（AS4809）、移动 CMIN2（AS58807）、联通 Premium（AS10099）三条优化线路，还和 Google 等本地运营商直连。官方自己的建议是：“如果延迟不是关键问题，考虑用洛杉矶 E-Commerce 套餐。”第三方整理的三网参考延迟：CN2 GIA-E 洛杉矶约 130–155ms，香港 30–50ms，东京 60–80ms。延迟敏感就上香港/东京的 Ultra 系列，追求性价比就选 GIA-E。

## 退款规则：30 天是从注册账号那天算的

这是最多人踩坑的地方。搬瓦工的 30 天退款，起算点是**账户注册时间**，不是你买 VPS 的时间。注册账号超过 30 天，哪怕你前一天刚下第一单，退款申请也会被拒。所以正确做法是想买了再去注册账号，别提前注册闲置。

官方条款列的条件还有几条：账户累计付款不超过 $60、付款次数不超过 10 次；账户下 VPS（包括已取消的）不超过 3 个；流量没有超标使用；分配的 IP 不在任何黑名单里；退款权每个身份只能用一次。符合条件的新用户可以在面板里直接提交退款申请，流程走完后账户下所有 VPS 立即停止，数据、快照、备份不可逆删除——提交前记得备份。还有一点要清楚：**续费不适用退款政策**，退款只覆盖符合条件的新购。

## 和其他 VPS 比该选谁

“VPS主机推荐”没有标准答案，几个常见场景的分工大致是这样：

- **访客在国内、跑网站或代理**：搬瓦工和 DMIT 的 CN2 GIA 是这个场景的第一梯队；搬瓦工的优势是 KiwiVM 面板功能全、机房可以免费换，GIA-E 20G 年付 $169.99 的门槛在 GIA 线路里算低的。
- **预算极限**：RackNerd 黑五价格低到离谱，但性能一般、客服响应慢、热门配置容易断货，适合对稳定性不敏感的用途。
- **学习、测试、短期项目**：Vultr 按小时计费，用完销毁没有沉没成本，比任何包年方案都适合试错。
- **客户在海外、习惯宝塔面板**：Vultr 或 DigitalOcean 的机房选择和按需计费更合适。
- **完全不想碰命令行**：Cloudways 这类托管平台帮你管系统，代价是价格高出一截。

搬瓦工明确不适合两类人：需要 Windows 系统的，和没有基本 Linux 命令行能力、也不打算学的。它是纯自助管理服务，官方不提供系统运维支持，这也是它能把这个价格做下去的原因。👉 开通 80G KVM 常规套餐，月付 $19.99 起先试一个月

## 购买流程与易错点

下单路径：选套餐 → 选机房和计费周期 → 注册账号 → 填优惠码 → 支付。支持支付宝、PayPal、信用卡和银联，付款后几分钟内自动开通，不需要等人工审核。

三个容易出错的地方：

1. **先注册再买，别反着来**。前面说过，退款窗口从注册时间起算，提前注册账号等于白白消耗退款期。
2. **限量套餐会缺货**。搬瓦工部分热门方案长期显示 out of stock，需要蹲补货，看到有货别犹豫太久。
3. **升级有边界**。KiwiVM 支持同系列内升级补差价（比如 GIA-E 20G 升 40G），但跨系列升级（比如 GIA-E 升香港 Ultra）一般要新开实例，起步就选对系列更省事。

## 常见问题

**搬瓦工能装 Windows 吗？** 不能。全系只有 Linux 发行版和可引导 ISO，需要 Windows 就得看别的平台。

**买错了机房怎么办？** GIA-E 和 KVM 系列在 KiwiVM 面板里可以免费一键迁移，GIA-E 有 11 个机房可选；但香港、东京、大阪等 Ultra 节点不可迁移。

**流量用超了会怎样？** 套餐流量按月计，超额部分官方会按套餐条款处理，对流量敏感的用途建议按月用量的 1.5 倍选档。

**优惠码在哪里填？** 结账页的「Promotional Code」输入框，填入后点「Validate Code」，价格更新了才算生效。
